# Модульна контрольна робота. Варіант 1

Номер у списку: **5**.

Робота складається з двох завдань: побудови RDF-графа з таблиці авіарейсів і виконання трьох SPARQL-запитів до Wikidata.

## 1. Склад файлів

| Файл | Призначення |
|---|---|
| `gen_data.py` | Наданий генератор початкових даних |
| `flights.csv` | Таблиця рейсів, отримана для seed 5 |
| `params.json` | Пороги класифікації рейсів |
| `build_graph.py` | Перетворення таблиці на RDF-граф |
| `graph.ttl` | Результат першого завдання у форматі Turtle |
| `q1.rq`, `q2.rq`, `q3.rq` | Три SPARQL-запити другого завдання |
| `run_queries.py` | Виконання запитів і збереження результатів |
| `q1.csv`, `q2.csv`, `q3.csv` | Результати SPARQL-запитів |
| `meta.json` | Дата й час отримання результатів |
| `ANSWERS.md` | Відповіді за першими рядками CSV |
| `requirements.txt` | Залежності Python |

## 2. Запуск

Потрібні Python 3.9 або новіший та підключення до інтернету для другого завдання.

Встановлення пакетів:

```bash
python -m pip install -r requirements.txt
```

Генерація початкових даних:

```bash
python gen_data.py --seed 5
```

Побудова RDF-графа:

```bash
python build_graph.py flights.csv params.json graph.ttl
```

Виконання SPARQL-запитів:

```bash
python run_queries.py
```

## 3. Завдання 1: RDF-граф авіарейсів

Усі ресурси створюються у просторі імен `http://example.org/mkr/`.

Під час обробки даних скрипт:

- нормалізує ідентифікатори рейсів, назви міст і дати;
- об'єднує дублікати рейсів в один RDF-вузол;
- створює класи `Flight`, `BudgetFlight`, `LongFlight`, `Airline`, `City` і `Country`;
- додає для властивостей `rdfs:domain` та `rdfs:range`;
- класифікує рейси за порогами з `params.json`;
- не додає `priceEur`, якщо ціна відсутня;
- подає відомості про затримку через RDF-reification;
- позначає рейси з країн, з яких вилітає щонайменше два рейси, властивістю `fromBusyCountry`.

Параметри для seed 5:

| Параметр | Значення |
|---|---:|
| `budget_threshold_eur` | 119 EUR |
| `long_flight_min` | 210 хв |

Поточний файл `graph.ttl` містить **284 RDF-трипли**.

## 4. Завдання 2: SPARQL-запити до Wikidata

Для номера 5 використано такі параметри:

| Параметр | Значення |
|---|---|
| Клас | `Q8502` — гора |
| Країна | `Q39` — Швейцарія |
| Властивість | `P2044` — висота над рівнем моря |
| Поріг | 3500 м |

Запити:

- **Q1** — 20 найвищих гір Швейцарії вище 3500 м з необов'язковим офіційним сайтом;
- **Q2** — 10 регіонів із найбільшою кількістю гір, якщо в регіоні їх щонайменше три;
- **Q3** — 10 гір із регіонів Швейцарії з найбільшим населенням.

`run_queries.py` надсилає запити до `https://query.wikidata.org/sparql` із заголовком `User-Agent: mkr1/1.0`, створює CSV-файли та записує час виконання в `meta.json`.
